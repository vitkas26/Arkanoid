# Arkanoid Christmas

Небольшой арканоид для Android. Игрок двигает ракетку, отбивает мяч и уничтожает восемь блоков. За каждый блок начисляется 10 очков.

## Управление

- Нажмите **Start game**.
- Перемещайте палец по игровому полю, чтобы двигать ракетку.
- На устройстве с клавиатурой используйте стрелки влево/вправо или `A`/`D`.
- После победы или поражения нажмите **Play Again**.

Поле имеет внутренний размер 400 × 700 игровых единиц и масштабируется целиком под экран. Правила игры не используют пиксели Android, `dp` или объекты `View`.

## Сборка

Нужны JDK 17 или новее, Android SDK 36 и Gradle Wrapper из репозитория. Укажите путь к SDK через `ANDROID_HOME` или локальный `local.properties` (он не коммитится).

```sh
./gradlew :app:assembleDebug
./gradlew :app:testDebugUnitTest
./gradlew :app:connectedDebugAndroidTest
```

APK создаётся в `app/build/outputs/apk/debug/app-debug.apk`. Последняя команда требует подключённое Android-устройство или запущенный эмулятор.

## Устройство проекта

- `game/GameEngine.kt` — состояние, движение мяча, столкновения, счёт и окончание игры. Это обычный Kotlin без Android API.
- `GameView.kt` — рисунок поля и преобразование касаний из экранных пикселей в игровые координаты.
- `MainActivity.kt` — запуск, кадровый цикл через `Choreographer`, результат, повтор и сохранение состояния при пересоздании Activity.
- `app/src/test` — JVM-тесты правил игры.
- `app/src/androidTest` — проверки запуска и состояния экрана на Android.

Описание выполненных задач и критериев приёмки находится в `docs/TICKETS.md`.
